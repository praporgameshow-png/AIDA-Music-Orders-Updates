# AIDA Music Orders — Updates

Публичный канал обновлений AIDA Music Orders.

Этот репозиторий используется установленной клиентской версией программы для проверки и загрузки официальных обновлений.

Текущая стабильная версия: **v1.0.3 FINAL**.

В v1.0.3 синхронизированы OWNER, CUSTOMER и UPDATE из одного финального source. Исправлены ограниченные YouTube-клипы через PO Token HTTP + exact-ID LOCAL fallback, добавлен VK FAST/FALLBACK, пробный период CUSTOMER установлен на 48 часов.

Актуальные бинарные файлы публикуются в GitHub Releases.
